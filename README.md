# Ejercicio 3 : Menú del Colmado

## Descripción
Este programa consiste en un sistema de ventas sencillo para calcular el total a pagar según los productos seleccionados y el método de pago elegido.

La aplicación funciona mediante los siguientes componentes:
* **ComboBox:** Despliega la lista de productos disponibles con sus respectivos precios.
* **TextBox:** Recibe la cantidad de unidades que el cliente desea comprar.
* **RadioButton:** Permite seleccionar la forma de pago (p. ej., efectivo, tarjeta, transferencia).
* **Label:** Muestra el cálculo final del total a pagar en función de la cantidad, precio y/o método de pago seleccionado.
